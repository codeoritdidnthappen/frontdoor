EntryMap illustration set

Seven standalone inline SVGs drawn from the concept boards: soft two-tone line work, pale blue and pale lavender fills, one saturated marigold element each, sitting in a pale lavender field. Every colour is a CSS custom property, so they follow the theme and the high-contrast mode. All are aria-hidden with no fixed width or height — the surrounding copy carries the meaning and the app decides the size.
